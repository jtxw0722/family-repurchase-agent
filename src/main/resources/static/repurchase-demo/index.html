手动入库

同一商品已有档案时合并入库，没有时自动创建。入库日期默认今天，填写过去日期时从该日估算消耗；确认当前库存后，更早的入库已被该数量覆盖。包装转重量须填写明确单包装规格。

不兼容明细

自然日按 Asia/Shanghai 计算，完整可用天数向下取整。库存与日均消耗按商品规则的标准单位展示，数量同步换算；“袋”与重量不混用。
