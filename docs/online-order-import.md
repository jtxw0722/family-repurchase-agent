# 在线订单导入

## 使用

1. 在“订单导入”选择本地 CSV/XLSX 并填写家庭归属人，点击“解析并预览”。
2. 正常记录默认勾选。赠品、零元支付、疑似重复、归一化失败、规格/金额异常、超出同单位历史中位数上下三倍范围的记录默认不勾选。
3. 红色字段先修正；黄色提示保留原自动判断，人工核对后可勾选。金额为人民币元，“标准总含量”已经包含购买件数，不要再次乘件数。
4. 确认时后端重新校验并查重，只保存勾选记录；疑似重复行跳过并报告。零元及赠品手动保存后仍排除价格基线。
5. 每页 50 条，勾选状态跨页保留。“勾选正常记录”作用于全部页，不会勾选异常行；计数显示全部页的勾选总数。
6. 清空预览、选择新文件或关闭页面会丢弃未保存预览。

## 格式与范围

按用户提供的中文订单导出表头适配，支持淘宝/天猫、京东、拼多多商品链接的平台识别；不承诺识别各平台所有版本的任意列名。

必要列：订单提交时间、订单状态、商品名称、型号款式、商品数量、实付金额。可用业务列：订单编号/主订单编号/子订单编号、店铺名称、商品链接、商品金额、运费。

只处理“交易成功”订单及对应商品续行，关闭/未完成交易的跳过数量在预览中显示。其他列如收货人、电话、地址、物流公司、物流单号均忽略。

限制：原文件 10 MiB、5000 行、100 列；XLSX 第一张工作表的第一行为表头，ZIP 总展开量不超过 32 MiB。CSV 支持 UTF-8/BOM 和 GB18030。不支持的表头会拒绝解析，不会直接入库。

## 应用层隐私边界

- JSON Base64 上传只包含内容、格式和用户指定归属人，不传原文件名或路径，不使用可能落盘暂存的 multipart。
- CSV/XLSX 均在内存解析，不创建上传文件或解压目录；如果其他组件开启 POI 临时文件模式，则拒绝在线 XLSX 解析。
- 不调用外部模型。不保存原始行或原文件，原始订单号只在本次内存中分组和分摊使用。
- 不输出上传内容、解析原始异常或数据库异常原文；上传协议对象的字符串表示固定脱敏。
- 预览/确认响应使用 `Cache-Control: no-store`；浏览器不把预览写入 localStorage、IndexedDB 等持久缓存。
- 只保存用户确认的商品名、归一化名、规格、人民币金额、标准总含量、单位、平台、日期、指定家庭归属人和店铺；来源为固定标记 `online-import`，`source_text` 和 `note` 为空。
- 预览行号、核对提示、原订单号、原文件名和收货物流信息均不入库，没有新增数据库表或字段。
- 查重使用归属人、日期、平台、商品名、规格、总含量、单位、金额，因不保存原始订单号而标记为“疑似重复”。同日同价同商品的不同购买可能需人工核对。
- 本隐私边界覆盖新增在线接口；旧服务器路径导入 API 保持兼容，仍沿用原有批次及来源路径记录行为。

## 部署

更新 JAR、重启服务并强制刷新页面。项目现有 `127.0.0.1:8080` + SSH Tunnel 方案无需新增上传目录或磁盘权限。

若另配 Nginx，可在现有 server 中增加以下 location，保留实际已有的认证、TLS 和访问控制配置。同时确认代理及第三方审计未记录请求体，不开启请求体 debug 日志。

```nginx
location /api/tools/online-order-import/ {
    # 10 MiB 文件转 Base64 约 13.34 MiB，另预留 JSON 开销。
    client_max_body_size 15m;
    client_body_buffer_size 15m;
    client_body_in_file_only off;
    proxy_request_buffering off;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_cache off;
    proxy_pass http://127.0.0.1:8080;
}
```

JAR 不会自动修改服务器代理。Nginx 在请求体超过内存缓冲时可能写临时文件，代理请求缓冲默认开启，依据：[请求体缓冲](https://nginx.org/en/docs/http/ngx_http_core_module.html#client_body_buffer_size)、[代理请求缓冲](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_request_buffering)。

## 验证范围

使用与用户表头一致的合成 CSV/XLSX，覆盖隐私列忽略、编码、购买件数折算、支付异常提示、赠品、查重、无效字段、关闭交易跳过、确认前重新校验和事务回滚。目前用户提供的是表头截图；真实导出文件及其他列名版本仍需脱敏样本验证。
